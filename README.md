# Arm-Based CAN Digital Instrument Cluster

This project implements an ARM-based CAN Digital Instrument Cluster that uses a 16x2 LCD display to show real-time automotive parameters such as speed, engine temperature, indicators, and headlights. It demonstrates embedded C programming on ARM microcontrollers, CAN bus communication, and digital instrumentation design.

✨ Features
🚗 Speed Display – Real-time vehicle speed monitoring

🌡️ Engine Temperature – Continuous temperature updates

💡 Indicators & Headlights – Status display for turn signals and headlights

📡 CAN Bus Communication – Reliable ECU data exchange

🖥️ LCD Interface – User-friendly 16x2 display

🛠️ Technologies Used
Microcontroller: ARM-based MCU

Programming Language: Embedded C

Communication Protocol: CAN bus

Display: 16x2 LCD

Development Tools: Keil uVision / GCC ARM toolchain

Open the project in your ARM development environment (Keil / GCC ARM).

Compile and flash the firmware to your ARM microcontroller.

Connect the LCD and CAN bus peripherals.

Observe speed, temperature, and status indicators on the LCD.

📚 Learning Objectives
Understand CAN bus communication in automotive systems

Implement LCD interfacing with ARM microcontrollers

Practice embedded C programming for real-time monitoring

Explore digital instrumentation design for vehicles

⚠️ Limitations
Currently supports only basic parameters (speed, temperature, indicators, headlights)

No advanced graphics (limited by 16x2 LCD)

Requires manual calibration for sensor inputs

🔮 Future Improvements
Upgrade to graphical LCD/TFT display for richer UI

Add more parameters (fuel level, battery voltage, warning alerts)

Implement data logging via SD card

Integrate with OBD-II interface for extended diagnostics
